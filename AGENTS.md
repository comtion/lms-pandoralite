## Modern Web Development

For all frontend, UI, UX, HTML, CSS, JavaScript, and React work:

- Use the installed Modern Web Guidance skill.
- Prefer modern web platform APIs over legacy JavaScript solutions.
- Consider browser compatibility before adopting new APIs.
- Prefer native HTML/CSS capabilities where practical.
- Follow accessibility best practices.
- Optimize for Core Web Vitals.
- Avoid unnecessary JavaScript, polyfills, and dependencies.
- Use progressive enhancement for features with limited browser support.
